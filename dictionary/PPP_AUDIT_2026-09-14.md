## NEW CANONICAL STARTER RULE

The first dictionary is NOT generated by Matryoshka coverage alone.

Correct architecture:

1. Define a frequency/usefulness Essential Core independently.
2. Essential words cannot be displaced merely because another word creates a richer Matryoshka family.
3. Build the strict Matryoshka graph over/around the Essential Core.
4. Use remaining flexible slots to add high-value bridge/family words.
5. Every added bridge must justify its cognitive cost by meaningful strict coverage.
6. Final beginner list remains 300–500 words, but its composition is frequency-first and Matryoshka-organized.

Candidate implementation:
- Mandatory Essential Floor: cleaned top-frequency vocabulary (exact cutoff to be fixed after lexical/POS cleanup).
- Flexible Matryoshka Slots: fill remaining capacity up to the 300–500 target by strict graph value.
- Direct/Fallback words are permitted when no good strict chain exists.

Therefore:
FREQUENCY CORE determines WHAT must be learned.
MATRYOSHKA determines HOW as much of it as possible is organized.
