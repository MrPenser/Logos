0. Letter Matryoshka — визуальный базовый словарь 300–500 частотных слов.
1. Core Meanings — основные значения и части речи.
2. Semantic Extensions — полисемия и переносные значения.

Canonical direction:
FORM → CORE MEANING → SEMANTIC FIELD → COLLOCATION → PHRASAL → IDIOM → NATIVE NUANCE

## Meta-learning axis — canonical working model

The Stage 0 → Stage 6 chain describes **what content layer is opened**.

A separate functional cycle describes **how conscious, purposeful learning of any object is completed**:

`INTENT -> MATRYOSHKA -> SATOR -> VERIFY -> next cycle if required`

- `INTENT` — explicit learning target.
- `MATRYOSHKA` — controlled variation / comparison.
- `SATOR` — candidate invariant / underlying-structure extraction, including contextual invariant extraction.
- `VERIFY` — correctness, unseen-context transfer, and delayed verification through time.

Time, repetition count, and spacing are parameters of traversal, not additional fundamental functions.

Human mnemonic: a clockwise circular learning dial with learner-specific stage durations. Machine representation may remain ordinary state/timing data.
