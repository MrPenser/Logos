# LOGOS — Learning Chain

0. Letter Matryoshka — визуальный базовый словарь 300–500 частотных слов.
1. Core Meanings — основные значения и части речи.
2. Semantic Extensions — полисемия и переносные значения.
3. Collocations — устойчивые сочетания и частотные блоки.
4. Phrasal Verbs — глагол + частица.
5. Idioms — недекомпозируемые устойчивые значения.
6. C1 / Natural Speech — нюансы, регистр, естественная коллокационность и речь.

Canonical direction:
FORM → CORE MEANING → SEMANTIC FIELD → COLLOCATION → PHRASAL → IDIOM → NATIVE NUANCE
