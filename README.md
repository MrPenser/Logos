# LOGOS — Project State v0.1

**Date:** 2026-09-14  
**Status:** INITIAL BACKUP / CANONICAL BASELINE

## 1. Назначение

LOGOS — система изучения английского с абсолютного нуля, построенная как последовательное раскрытие уже знакомого материала от визуальной формы слова к естественной речи.

Базовый механизм Stage 0 называется **«Матрёшка»**.

## 2. Каноническая цепь изучения

### Stage 0 — буквенная «Матрёшка»
Цель: быстро создать первый базовый словарь примерно из 300–500 очень частотных слов через строгие визуальные преобразования.

### Stage 1 — основные значения
Для уже зрительно знакомых слов раскрываются основные части речи и базовые значения.

### Stage 2 — смысловые расширения
Полисемия, переносные значения и семантические зоны уже знакомого слова.

### Stage 3 — устойчивые сочетания
Коллокации и частотные блоки. Единицей становится не отдельное слово, а устойчивое сочетание.

### Stage 4 — phrasal verbs
Знакомые глагольные основы раскрываются через частицы и образуют новые значения.

### Stage 5 — идиомы
Осваиваются конструкции, значение которых нельзя надежно вывести из отдельных компонентов.

### Stage 6 — C1-нюансы и естественная речь
Регистр, оттенки, естественная коллокационность, выбор между близкими формами, идиоматичность и естественная речь.

Иерархия:
FORM → CORE MEANING → SEMANTIC FIELD → COLLOCATION → PHRASAL → IDIOM → NATIVE NUANCE

## 3. Stage 0 — строгий канон

### 3.1. Жёсткое правило ребра
Для любого перехода u → v:
- длина v = длина u + 1;
- новая буква добавляется только слева или только справа;
- внутренние вставки, удаления, замены, перестановки запрещены;
- за один шаг добавляется ровно одна буква;
- после каждого шага результат является полноценным английским словом.

Формально:
- v = c + u  → L+1
- v = u + c  → R+1

### 3.2. Канонический пример
I → IN → PIN → PINE → SPINE  
Код: RLRL

### 3.3. Приоритет ранжирования Stage 0
1. строгая визуальная близость и простота преобразования;
2. частотность и полезность слов;
3. длина/плотность матрёшки;
4. лёгкость зрительного восстановления в обе стороны;
5. смысловая/поведенческая связность — только дополнительный бонус.

Смысл не может поднять слабую визуальную цепь выше более сильной визуальной.

### 3.4. Графовая модель
Словарь Stage 0 — не линейный список, а направленный ациклический граф (DAG):
- узел = допустимое слово;
- ребро = строгая операция +1 L/R;
- возможны ветвления;
- возможны слияния;
- направленных циклов быть не может, потому что длина слова всегда возрастает на 1.

### 3.5. L/R-код
Каждая цепь имеет пространственную подпись:
- L = буква добавлена слева;
- R = буква добавлена справа.

Код направления не заменяет буквенный контент. Полное конструктивное описание шага = (direction, letter).

## 4. Текущая вычислительная модель

### Matryoshka Score v1
После Visual Gate оцениваются:
- **F — Frequency Utility:** суммарная частотная ценность новых слов;
- **D — Density:** число новых слов и плотность строгих связей;
- **R — Recoverability:** глубина и однозначность восстановления к ядру.

Семантика в v1 не используется как числовой вес.

Текущий рабочий предел семьи: до 3 последовательных строгих добавлений.

### Текущие сильные ядра-кандидаты
A, I, HE, AN, AT, NO, ON, ALL, EAR, ILL.

Это **не финальный словарь**, а вычисленное стартовое ядро.

### Открытая проблема v2
Нужно разделить:
- Seed Utility — полезность самого ядра;
- Expansion Utility — полезность слов, которые ядро открывает.

Причина: редкое ядро может вести к очень частотным словам и искусственно подниматься в рейтинге.

## 5. Методика урока — рабочая гипотеза
Для новичка:
- около 10 матрёшек за урок;
- около 20–30 новых единиц;
- избегать перегрузки слишком похожими словами.

Это пока гипотеза для будущей экспериментальной проверки, а не окончательная норма.

## 6. Research Overlay

Отдельно исследуются три корпуса. Они являются **генераторами проверяемых гипотез**, но не доказательной базой автоматически.

### Лукашевич
Приоритет: буквенные преобразования, корни, обратное чтение, межъязыковые соответствия.

### Вашкевич
Приоритет: русско-арабские семантические соответствия, мотивация лексики/идиом, системные языки мозга, «симия».

### Шубин-Абрамов
Приоритет: «ВсеЯСветная Грамота», семантизация букв/буков, буквосочетания, кодовые матрицы, визуально-геометрические свойства знаков.

## 7. Integration Gate

Базовый словарь строится независимо от исследовательских веток.

Любая идея из Лукашевича / Вашкевича / Шубина:
1. формулируется как отдельная проверяемая гипотеза;
2. проверяется на фактах/корпусе;
3. сравнивается с Core;
4. только после PASS может добавлять новый тег, тип связи или дополнительный режим поиска.

Она не может задним числом менять строгие правила Stage 0 без отдельного архитектурного решения.
